# Phòng Chat Nhóm

Triển khai: đẩy lên GitHub -> Render (Web Service, Build: npm install, Start: npm start, Free).
API: GET /api/messages ; POST /api/messages {"sender":"Bot","text":"Xin chào"}
Lưu ý: tin nhắn lưu trong bộ nhớ, mất khi server khởi động lại.
